# Laravel Fundamentals

Project developed to practice basic features of the Laravel framework, using React in the front-end of a single page application, and SQLite database.

## Required/Used tools
  - PHP (8.5)
  - Laravel (5.32.0)
  - Composer (2.10.3)
  - Node (26.13.0)

## How to Run
- From the project's root:
```bat
   php artisan key:generate
   composer install
   composer run dev
```
